# 🦠 Malaria Detection using Deep Learning (CNN) – Healthcare AI 

## 📌 Overview

This project uses a Convolutional Neural Network (CNN) to classify malaria-infected and uninfected blood cell images.

## 🎯 Objective

Develop a deep learning model capable of assisting in medical image classification.

## 🧠 Techniques Used

* CNN (Convolutional Neural Networks)
* Image preprocessing (normalization, HSV conversion)
* Data augmentation
* Model evaluation (accuracy, confusion matrix, classification report)

## 📊 Results

* Achieved strong classification performance
* Reduced overfitting using data augmentation
* Improved generalization on unseen data

## 🛠 Tools

Python, TensorFlow/Keras, NumPy, Matplotlib

## 📈 Impact

Demonstrates how AI can support healthcare diagnostics and decision-making.
